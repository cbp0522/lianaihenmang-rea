# 节奏记录 PRD

## 产品目标

给专注练习提供一张可连续记录轮次的小卡片。新用户可以快速记录每轮，误触可撤销。记录留在设备。

## 设计规范

使用左对齐卡片、系统动态字体、靛蓝主操作与留白。数值旁标明单位「轮」，底部提供撤销与开启新一轮会话。按钮支持 VoiceOver。界面沿用系统深浅色，所有可见文字使用简体中文。使用 SwiftUI 与本地存储，无需网络或账号。

## 页面与导航

单页面会话卡片，开始新会话通过确认对话框完成。

## 用户流程

打开 → 记录 → 选择撤销或开始新会话 → 保存。

## 数据与状态

本地状态包含当前非负轮次及存储错误。

## 关键业务规则

每次成功记录增加一轮。清零需要确认。

## 异常状态

保存失败显示原值及重试提示，损坏文件先备份再恢复。

## 非目标

账号、云同步、订阅与历史分析。

## 优先级与里程碑

先完成本地持续计数，再验证界面和恢复路径。

## 功能与验收

### F01 加载本地轮次

依据类型为原创。

初次打开显示 0 轮。重新创建视图模型或强制结束后重开时，读回上次已保存的计数。持久化与错误恢复是原创产品要求。临时保存失败时保留当前数值并允许下次操作重试。数据损坏时，经确认保留原文件的独立备份后才能重置；若已恢复为有效记录，则直接加载。

### F02 记录与撤销

依据类型为原创。

每点一次「记录一轮」加一。点「撤销一轮」减一，0 轮禁用撤销，快速连点逐次累计。撤销是原创产品要求。

### F03 开始新会话

依据类型为原创。

计数大于 0 时可以选择开始新会话。确认后计数持久化为 0，取消保留当前数值。确认步骤是原创产品要求。
