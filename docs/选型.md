# 工具选择

| 工具 | 本次用法 |
|---|---|
| [Kandev](https://github.com/kdlbs/kandev) | 本机安装 0.102.0 和隔离 SQLite 状态，用于工作区、看板、工作树与会话。 |
| [Codex CLI](https://github.com/openai/codex)、[Claude Code](https://github.com/anthropics/claude-code) | 复用已有登录。按任务规划、实现与独立评审分工。 |
| [Gemini CLI](https://github.com/google-gemini/gemini-cli)、[Antigravity CLI](https://antigravity.google/docs/cli/getting-started) | 默认使用已登录且实际跑通的 Antigravity 1.5.13，保留企业 Gemini CLI 可选入口。Google 自 2026 年 6 月 18 日停止 Gemini CLI 个人 OAuth 通道。Kandev 的原生 Antigravity ACP 是独立安装和登录的组件。 |
| [REA](https://github.com/morluto/rea) | 评估了本地分析 CLI 和 MCP。本阶段用标准 ZIP、plist 和 Mach-O 结构工具覆盖证据需求。 |
| [Craft Anything](https://github.com/storytold/craft-anything) | 评估了行为与洁净室实现流程。iOS 验收以可重现的 Xcode UI 树、截图、录屏和人工核对为主。 |
| [MobSF](https://github.com/MobSF/Mobile-Security-Framework-MobSF)、[Ghidra](https://github.com/NationalSecurityAgency/ghidra)、[Maestro](https://github.com/mobile-dev-inc/Maestro) | 作为未来按需工具。当前路径无容器和 JVM 常驻负担，使用 XcodeBuildMCP 操作自制样本，FFmpeg 和 Vision 处理画面。 |

第三方样本研究记录只保留合法来源、配置线索和可观察行为。输出用独立需求、设计与资产实现。SDK 名称、内部规则和服务端行为的结论以实际证据为准。
